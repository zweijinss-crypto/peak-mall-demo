本目录 3 份法律文件(`privacy-policy.md` `terms.md` `refund.md`)**全部是骨架占位**,**不是最终法务文档**。

每份文件顶部都有 **"⚠️ MUST NOT SHIP WITHOUT LAWYER ⚠️"** 警告。

**未让律师审核前不得用于生产环境**。

## 3 份骨架

| 文件 | 章节 | 用途 |
|---|---|---|
| `privacy-policy.md` | 12 章 | PIPL(个人信息保护法)合规 + GDPR 兼容 |

## 律师审核清单(launch 前必做)

- [ ] 核实公司名称、注册地址、联系电话、邮箱
- [ ] 核实司法管辖区(默认中国大陆)
- [ ] 核实生效日期 + 最近更新日期
- [ ] PIPL 第 38-39 条评估(若跨境)
- [ ] 数据处理协议(DPA)与第三方(支付网关/物流/客服)签署
- [ ] 明确"商家"与"平台"的法律关系(自营 vs 平台模式)
- [ ] 评估《电子商务法》《消费者权益保护法》《广告法》合规
- [ ] 评估《禁止传销条例》(已剔除多级分销,但"商业返佣"边界)
- [ ] 退款流程与支付网关对接
- [ ] 用户协议"点击接受"的法律效力测试
- [ ] 隐私政策"撤回同意"的工程实现

## 红线 vs 合规对照(给律师参考)

| 项 | 源站(peak-mall.com) | 合规版(本包) |
|---|---|---|
| 加密货币支付 | USDT-TRC20 | ❌ 不接受 |
| 多级分销 | 三级 + 佣金 | ❌ 不实现 |
| 邀请码 | 注册必填 | ✅ 已剔除 |
| 资金密码 | 6 位 | ❌ 不实现 |
| 提现地址 | TRC20 钱包 | ❌ 不实现 |
| 商业返佣 | 自助调节 | ❌ 不实现 |
| 个人信息范围 | 含金融敏感 | ✅ 仅普通商城必要 |
